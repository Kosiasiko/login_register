# Login & Register Web App

A full-stack PHP authentication system with user registration, login, session management, and logout. Deployed on Render with a managed MySQL database on Aiven.

🔗 **Live Demo:** https://login-register-app-7n85.onrender.com

---

## ✨ Features

- User registration with first name, last name, email, and password
- Secure password storage using **bcrypt** (`password_hash`)
- User login with password verification (`password_verify`)
- Session-based authentication
- Protected pages (homepage requires login)
- Logout functionality
- Switch between Sign In / Sign Up forms with JavaScript
- Responsive UI with Font Awesome icons
- Deployed as a Docker container on Render
- SSL-encrypted MySQL connection to Aiven
